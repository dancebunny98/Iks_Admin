Настройки отправки

Каждый тип события отправляется в свой webhook. Адреса останутся только в загруженных или скачанных файлах.

Загрузить конфиги

Загруженные файлы обрабатываются в браузере. Прочие параметры основного конфига сохранятся при экспорте.

Скачать конфиги

Скачайте оба файла в каталог addons/counterstrikesharp/configs/plugins/IksAdmin_DiscordPunishments/. Webhook URL сохраняются в файлах, поэтому храните их приватно.
