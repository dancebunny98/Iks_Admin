# IksAdmin Discord Studio

Откройте `index.html` в браузере. Сервер и установка зависимостей не нужны: редактор работает локально, без отправки конфигов и webhook URL на сторонний сайт.

1. Нажмите **Загрузить конфиги** и выберите текущие `IksAdmin_DiscordPunishments.json` и `warnings.json` из каталога `addons/counterstrikesharp/configs/plugins/IksAdmin_DiscordPunishments/`.
2. Выберите событие слева. Во вкладке **Редактор** настройте текст, embeds и ссылочные кнопки. Во вкладке **JSON** можно вставить полный JSON сообщения из Discohook и нажать **Применить JSON**.
3. Через **Тестовые данные** задайте значения заполнителей и проверьте предпросмотр и замечания над ним.
4. Через **Настройки webhook** укажите отдельные адреса для варнов игроков и модераторов. Нажмите **Скачать конфиги** и скачайте оба файла в каталог конфигурации плагина. Затем перезапустите или перезагрузите модуль.

Кнопка **Проект** скачивает резервную копию обоих конфигов и тестовых данных для последующей загрузки в редактор. Сообщения не отправляются в Discord из браузера. Интерактивные кнопки, формы и локальные вложения Discohook не поддерживаются webhook модулем; допустимы только ссылочные кнопки `style: 5` с HTTPS URL.

Полный формат сообщений, ограничения и список заполнителей: `docs/discord-messages.md` в репозитории или `DISCORD_MESSAGES.md` в архиве Discord-модуля.
